# Don Works — website

The Next.js landing page for **[donworks.co.uk](https://donworks.co.uk/?utm_source=donworks&utm_medium=readme&utm_campaign=donworks_oss)** — the umbrella for the open-source tools we build at [Revitt](https://revitt.co/?utm_source=donworks&utm_medium=readme&utm_campaign=donworks_oss).

Everything is open source under AGPL-3.0 on the [Don Works org](https://github.com/Don-Works).

## Stack

Next.js 15 · Tailwind CSS v4 · JetBrains Mono. Deployed on Vercel.

## Local Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```
